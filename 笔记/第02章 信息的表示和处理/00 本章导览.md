## 一、本章的内在逻辑

```text
                一串 w 位的比特  x = [x_{w-1} … x_1 x_0]
                                │
              ┌─────────────────┼──────────────────┐
              ▼                 ▼                  ▼
        无符号编码 B2U      补码编码 B2T       浮点编码 IEEE 754
        （只有非负数）     （正负都行）      （带小数与巨大范围）
              │                 │                  │
              └────────┬────────┘                  │
                       ▼                           │
                 整数运算（模 2^w 的环）             │
                 加法/乘法/移位/取负                │
                       │                           │
                       ▼                           ▼
              ┌────────────────────────────────────────┐
              │  有限位宽 ⇒ 溢出、截断、舍入、精度损失   │
              └────────────────────────────────────────┘
```

**一句话**：本章讲的是"**同一串比特，换个编码就是另一个数**"，以及"**位数有限，所以必须有溢出和舍入**"。

## 四、学习建议

> [!TIP]
> 这一章**必须动手算**。纯看会以为懂了，一算就露馅。建议准备一张纸，把教材里的每个例子自己推一遍：
> - `B2T_4([1011]) = ?`
> - `(short)0xFFFF` 转 `unsigned short` 是多少？
> - `-8 >> 1` 与 `(unsigned)-8 >> 1` 差多少？
> - `1e20 * 1e20 * 1e-20` 为什么会是 `∞`？

**推荐顺序**：2.1 → 2.2 → 2.3 → 2.4 → 2.5（严格顺序，后一节都依赖前一节）

> [!WARNING]
> 2.2.4（有符号/无符号转换）和 2.3.2（补码加法溢出）是本章最容易"以为自己懂了"的两处。考试里 80% 的坑都在这两个地方。

## 六、常见误区

1. **以为 `int` 溢出会"报错"**：C 里有符号溢出是 **UB**，无符号是**回绕**，都不会报错。
2. **以为 `-1 < 0U` 为真**：`-1` 会被转成 `UINT_MAX`，比较结果是**假**。
3. **以为 `float` 能精确表示 `0.1`**：不能，二进制小数表示不了 1/10。
4. **以为浮点加法满足结合律**：`(a+b)+c ≠ a+(b+c)`，这是优化器的噩梦。
5. **把"截断"和"舍入"混淆**：整型是截断（丢高位），浮点是舍入（就近取）。
