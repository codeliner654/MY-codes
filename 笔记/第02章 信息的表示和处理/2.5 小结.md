## 🎯 核心结论

| # | 结论 |
| :-: | :--- |
| 1 | 全章只有**一套位**和**三套解释**：无符号（$B2U$）、补码（$B2T$）、IEEE 754 浮点 |
| 2 | 整数运算是**在模 $2^w$ 的环里**做的，与数学整数的差异全来自"取模"这一步 |

| 5 | 安全漏洞、精度事故、跨平台 bug，八成都能追到"位被按错误的规则解释了" |

## 2.5.2 编码体系总表

| 编码 | 解释规则 | 值域（$w$ 位） | 运算规则 | 溢出行为 | 典型位宽 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **无符号** | $B2U_w(\vec{x})=\sum x_i2^i$ | $[0,\ 2^w-1]$ | $\bmod\ 2^w$ | 明确定义：回绕 | 8 / 16 / 32 / 64 |
| **补码** | $B2T_w(\vec{x})=-x_{w-1}2^{w-1}+\sum x_i2^i$ | $[-2^{w-1},\ 2^{w-1}-1]$ | $\bmod\ 2^w$ 后按补码读 | 有符号溢出 = **UB** | 8 / 16 / 32 / 64 |
| **IEEE 754 浮点** | $V=(-1)^sM2^E$ | float $\approx\pm3.4\times10^{38}$，double $\approx\pm1.8\times10^{308}$ | 精确算完再舍入 | 上溢→$\pm\infty$，下溢→非规格化/0 | 32 / 64 |
| 原码 / 反码 | 符号位 + 绝对值 / 按位取反 | $[-2^{w-1}+1,\ 2^{w-1}-1]$ | 需特殊处理 | 已淘汰（双零、需循环进位） | 历史 |

**同一串位的三种读法**（以 32 位 `0x80000000` 为例）：

```text
 位模式: 1000 0000 0000 0000 0000 0000 0000 0000

 按 unsigned 读 → 2147483648          （最高位权值 +2^31）
 按 int 补码读 → -2147483648  (TMin)  （最高位权值 -2^31）
 按 float 读   → -0.0                 （s=1, e=0, f=0 → 非规格化且尾数为 0）
```

这一行就是全章的缩影：**机器只搬 32 个 bit，含义完全取决于你告诉它按哪套规则解释。**

> [!TIP]
> 复习时拿 3 个位模式反复练：`0x80000000`、`0xFFFFFFFF`、`0x3F800000`。它们分别覆盖了"TMin / 全 1 / 浮点 1.0"这三类极端情况，能把整章的概念一次串起来（`0x3F800000` 按 float 读正好是 1.0：`s=0, e=127, f=0`）。

## 2.5.3 必须记住的十条结论

1. **无符号与补码只差最高位权值**：$+2^{w-1}$ vs $-2^{w-1}$，所以 $B2U-B2T=x_{w-1}2^w$。
2. **补码范围不对称**：$TMin=-2^{w-1}$、$TMax=2^{w-1}-1$，故 $\lvert TMin\rvert=TMax+1$。
3. **转换不改位**：`(unsigned)x` 与 `(int)u` 在汇编里常常一条指令都不生成，变的只是后续运算的语义（`sar`/`shr`、`setl`/`setb`）。
4. **扩展看符号、截断取模**：无符号零扩展、补码符号扩展；截断一律 $\bmod\ 2^k$，静默丢高位。
5. **C 的混合运算把有符号转成无符号**：`-1 < 0U` 为假，`sizeof` 参与的比较尤其危险。
6. **补码加减乘 = 先数学算、再 mod $2^w$**：加法溢出判据 `s < x`；补码正溢出 `x>0 && y>0 && s<0`。
7. **$-x=\sim x+1$，唯一例外是 $TMin$**：`-INT_MIN == INT_MIN`，`abs(INT_MIN) < 0`。
8. **乘常数用移位/LEA，除 $2^k$ 用右移 + 偏置**：负数必须加 $2^k-1$，因为右移是 floor 而 `/` 是 truncate。
9. **IEEE 754 四类编码**：规格化（$M=1+f$）、非规格化（$E=1-\text{bias}$，平滑趋 0）、无穷、NaN。
10. **浮点默认向偶数舍入，且不满足结合律/分配律**：$\infty-\infty=\text{NaN}$，`NaN != NaN`，比较浮点必须用误差范围。

记忆骨架（把 10 条压成 6 行）：

```text
 2^w ────── 无符号的世界 ──┐
                           ├── 同一个加法器：丢掉进位
 -2^(w-1) ~ 2^(w-1)-1 ─────┘
        │
        └── 取负 = ~x + 1；TMin 是唯一的洞

 (-1)^s × M × 2^E ── 另一个世界：不取模，改舍入
```

> [!IMPORTANT]
> 这十条的价值不在"背"，而在**看到任何一段位运算/类型转换代码时能立刻定位它在哪套规则里**。考试出综合题（给位模式求三种解释、给代码判断输出、写溢出检测）考的都是这张网，而不是单个公式。

## 2.5.4 常见面试 / 考试题

**Q1：`-1 < 0U` 是真还是假？为什么？怎么改？**

假。C 的通常算术转换规定：`int` 与 `unsigned` 同时出现时，`int` 被转成 `unsigned`，于是 `-1` 变成 `4294967295`，与 0 比较为假。修复办法：把常量写成有符号（`0`），或显式转 `(int)`，或干脆全程用有符号类型；编译器 `-Wsign-compare` 能抓这类问题。

**Q2：同一个 32 位字 `0x80000000`，按 `int`、`unsigned`、`float` 各是什么？**

```text
 int      → -2147483648（TMin，取负仍是自己）
 unsigned → 2147483648
 float    → -0.0（s=1，e=0 非规格化，f=0 → M=0，值 = -0）
```

三者位模式完全相同，只是解释不同——这正是"信息 = 位 + 上下文"的硬证据。

**Q3：怎样可移植地检测 `int` 加法溢出？为什么不能"先算完再判断"？**

因为 `a + b` 一旦溢出就是 UB，编译器可以假设它不发生并把后续判断优化掉（例如把 `if (a + b < a)` 直接删成假）。正确做法是**在算之前判断**，或用编译器内建：

```c
#include <limits.h>

int safe_add(int a, int b, int *r) {
    if ((b > 0 && a > INT_MAX - b) || (b < 0 && a < INT_MIN - b)) return -1;  // 先判断
    *r = a + b;
    return 0;
}

// 更省事：gcc/clang 内建，无 UB
if (__builtin_add_overflow(a, b, &r)) return -1;
```

对无符号则简单得多：`if (r < a) 溢出;`（因为溢出后结果必然变小）。

> [!WARNING]
> 反过来也要小心：**不要用 UB 来"试探"硬件**。`int x = INT_MAX; x++; printf("%d", x);` 在不同优化级别下可能打印 `-2147483648`，也可能被整段删掉——因为 UB 之后程序的行为不受任何保证。

**Q4：`0.1 + 0.2 == 0.3` 为什么是假？该怎么比较？**

`0.1` 的二进制是 `0.0001 1001 1001 …`（`0011` 无限循环），存进 float/double 时已经被舍入；`0.2`、`0.3` 同理。三者都带着各自的舍入误差，加起来自然不等于 `0.3` 的那份近似值。正确写法：

```c
#include <math.h>
int nearly_equal(double a, double b) {
    return fabs(a - b) <= 1e-9 * fmax(1.0, fmax(fabs(a), fabs(b)));  // 相对 + 绝对容差
}
```

若要"十进制精确"，用定点整数（以分为单位）或十进制浮点库，别用二进制浮点。

## 📌 重点速记

```text
一条主线   : 位 → 无符号/补码 → 模 2^w 的运算 → IEEE 754 + 舍入
两种解释   : B2U（0 ~ 2^w-1）  B2T（-2^(w-1) ~ 2^(w-1)-1）
一条恒等   : B2U - B2T = x_{w-1} · 2^w
两种扩展   : 无符号零扩展 ；补码符号扩展
一种截断   : mod 2^k
整数本质   : mod 2^w 的环；无符号回绕有定义，有符号溢出 UB
浮点形式   : V = (-1)^s × M × 2^E ；float 1/8/23 bias 127
浮点四类   : 规格化 / 非规格化 / 无穷 / NaN
浮点默认   : 向偶数舍入
浮点禁忌   : 结合律、分配律、== 比较、∞-∞
```

## ⚠️ 易错点

1. **把"章末小结"当成"可以跳过"**——考试最爱在这里出跨节综合题（例如"给定位模式，按三种类型分别求值"）。
2. **混用两套"溢出"语义**：无符号溢出是**明确定义的回绕**，有符号溢出是**UB**，二者不能用同一套判据。
3. **以为补码和浮点都是"符号位 + 数值"**——补码的符号位参与运算、有负权值；浮点的符号位只是一个正负号，与阶码尾数完全解耦。
4. **记混 $2^w$ 与 $2^{w-1}$**：无符号回绕用 $2^w$，补码的模也是 $2^w$，但范围边界是 $\pm2^{w-1}$。
5. **以为"精度"和"范围"是一回事**：float 的范围比 `int` 大得多，但精度只有 24 位，装不下所有 `int`。
6. **只记结论不记适用条件**：`s < x` 只对**无符号**成立；`x > 0 && y > 0 && s < 0` 只对**补码**成立。用错一个就是完全错误的判断。

## ✅ 自测

1. 32 位下 `(unsigned)-1`、`(int)0xFFFFFFFF`、`0xFFFFFFFF` 按 float 读各是什么？
2. 写出补码加法的正溢出判据，并说明为什么"两个正数相加得负数"必然是溢出。
3. float 的 bias 是多少？最小正的非规格化数是多少？
4. `x * 15` 与 `x / 8`（$x$ 为有符号）分别会被编译成什么操作？

<details>
<summary>参考答案</summary>

1. `4294967295`；`-1`；NaN（`s=0, e=255, f≠0`，因为 `0xFFFFFFFF` 的 `frac` 全 1）。
2. `x > 0 && y > 0 && s < 0`。两个正数相加若结果落回负区间，说明数学和超过了 $2^{w-1}-1$ 并被折回，只有溢出能做到。
3. bias = 127；最小正非规格化数 $= 2^{-23}\times2^{-126}=2^{-149}\approx1.4\times10^{-45}$。
4. `x * 15` → `(x << 4) - x`（或 LEA 组合）；`x / 8` → `leaq 7(%rdi),%rax; testq %rdi,%rdi; cmovns %rdi,%rax; sarq $3,%rax`。

</details>
