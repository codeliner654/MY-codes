## 四、学习建议

> [!IMPORTANT]
> 本章**不能只读**。必须打开终端，把教材里的例子自己编译、反汇编、单步：

```bash
# 生成汇编（不汇编、不链接）
gcc -Og -S mstore.c

# 生成目标文件并反汇编
gcc -Og -c mstore.c
objdump -d mstore.o

# 带源码行号一起看
gcc -Og -g -c mstore.c && objdump -d -S mstore.o

# 单步观察寄存器
gdb ./mstore
(gdb) disas multstore
(gdb) b *multstore
(gdb) run
(gdb) stepi
(gdb) info registers rip rsp rbp
```

**推荐顺序**：3.2 → 3.3 → 3.4 → 3.5 → 3.6 → 3.7 → 3.8 → 3.9 → 3.10 → 3.11 → 3.1（历史最后读，当前情回顾） → 3.12

> [!TIP]
> 3.6 是本章最花时间的一节（教材 29 页），**不要跳**。条件码 + 跳转 + 循环 + switch 是后面读任何汇编的基础。3.7 是第二大重点，栈帧一定要能默画。

## 六、常见误区

1. **把 `movq %rsi, %rdi` 读成"把 rdi 给 rsi"**：AT&T 是**源在前**，这条是 `rdi = rsi`。
2. **以为 `leaq` 会读内存**：它只算地址，`leaq (%rax),%rdx` 与 `movq (%rax),%rdx` 完全不同。
3. **以为 `%eax` 写 0 只改低 32 位**：写 32 位子寄存器会**清零高 32 位**。
4. **以为 `cmov` 是"条件跳转"**：它是条件**传送**，不改变控制流。
5. **以为 `push` 后内存就"没了"**：`pop` 只是移动 `%rsp`，内存内容还在。
6. **以为参数都走栈**：x86-64 前 6 个整型参数走寄存器，浮点另有 `%xmm0-7`。
